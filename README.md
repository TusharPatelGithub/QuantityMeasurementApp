# QuantityMeasurementApp

## Project Overview
The Quantity Measurement Application is designed to perform various unit measurements such as length, weight, volume, and temperature conversions.  
It follows an N-Tier Architecture and supports comparison, conversion, and arithmetic operations between different measurement units.

## Features
- Length unit comparison
- Unit conversion between measurement systems
- Arithmetic operations on quantities
- Temperature measurement support
- Persistent storage using SQL Server (UC16)
- N-Tier architecture implementation

## Tech Stack
- C#
- .NET 10
- SQL Server (MSSQL)
- ADO.NET
- Git & GitHub
